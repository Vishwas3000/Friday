Friday's wake-word models (D-035, research/16). Bundled unchanged except for one file name; licences checked 2026-10-17.

melspectrogram.onnx, embedding_model.onnx
  Source: openWakeWord v0.5.1 release assets, https://github.com/dscripka/openWakeWord (David Scripka).
  The embedding model re-implements Google's speech_embedding (https://tfhub.dev/google/speech_embedding/1, Apache-2.0);
  the melspectrogram model is an ONNX version of Torch's melspectrogram with fixed parameters.
  openWakeWord's code is Apache-2.0, and its README puts its included pre-trained models under
  CC BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/). We follow that stricter reading:
  non-commercial use only, with attribution.

hey_friday.onnx (published as "hey_Friday!.onnx")
  Source: https://github.com/fwartner/home-assistant-wakewords-collection, en/hey_friday, under the MIT licence below.
  It was trained with openWakeWord's training pipeline, whose negative training data is CC BY-NC-SA 4.0.
  Fine for this personal app; re-check before Friday is ever shared or sold.
